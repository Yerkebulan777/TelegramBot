## 🟢 НИЗКО — UX / сопровождение

### 1. Очистка папок экспорта — удаление дублей и архивация

Перенесено из `RevitBIMFusion/Docs/TODO.md #5`.

**Проблема.** В папках экспорта проекта (весь раздел проекта, все вложенные папки) со временем копится мусор: старые дубли одного и того же файла, посторонние файлы, которые там быть не должны. Занимают место, засоряют структуру.

**Задача.** Очистка применяется ко всем папкам раздела проекта, кроме папок, чьё имя начинается с символа `#` — такие папки исключены из обработки полностью (не сканируются, не трогаются).

**Решение.** Не реализовано. Черновой набросок лежит в `TelegramBot.Worker/BimLib/`:

- `Config/ExportFolderCleanupOptions.cs` — настройки (SectionName, пороги, маппинг папок)
- `Services/ExportFolderCleanupService.cs` — логика очистки с файловым маркером вместо реестра

Требуемая политика очистки (для реализации):
- Папки: `03_PDF`, `02_DWG` (NWC и DATA исключены)
- Папки с именем, начинающимся на `#`, — исключены из обработки
- Профильные файлы группируются по имени; применяется политика old/non-old
- Non-old (≤100 дней): самый новый → архив, остальные дубли → удалить
- Old (>100 дней): уникальный → не трогать, ≥2 дублей → оставить 3 свежих, остальные: <30 МБ удалить, ≥30 МБ в архив
- Посторонние файлы (не .pdf в PDF, не .dwg в DWG) → удалить безусловно
- Защита от частого запуска: маркерный файл `.cleanup_marker` в корне экспорта (один раз в день)

Предстоит: добавить фильтр исключения папок `#*` в логику сервиса, интеграция с DI и расписанием Worker.
