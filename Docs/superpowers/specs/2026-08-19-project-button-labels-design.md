# Выравнивание имён проектов в inline-кнопках

## Цель

Сделать подписи кнопок проектов одинаковой длины, чтобы список легче читался.

## Решение

При построении списка проектов имя каждой папки:

1. Ограничивается 50 символами. Если имя длиннее, последние три доступные позиции заменяются на `...`.
2. Дополняется пробелами справа до 50 символов.
3. Получает существующий префикс `📁 ` и неизменные callback data.

## Границы

Изменение применяется только к кнопкам на корневом уровне выбора проектов. Навигация, токены путей и подписи кнопок разделов и файлов не меняются.

## Проверка

Полная сборка `dotnet build TelegramBot.slnx` должна завершаться успешно.
