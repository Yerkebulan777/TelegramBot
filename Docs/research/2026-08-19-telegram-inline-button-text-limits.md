# Лимит текста inline-кнопки Telegram

Дата проверки: 2026-08-19.

## Вывод

Текст из **50 Unicode-символов**, включая добавленные справа пробелы, не противоречит опубликованным ограничениям Telegram Bot API. В официальной спецификации для `InlineKeyboardButton.text` не указан числовой верхний предел: это просто *label text on the button*. Следовательно, Telegram не даёт документальной гарантии конкретного максимума, но правило «обрезать и дополнять до 50 символов» не пересекается с опубликованным лимитом текста кнопки.

Отдельно ограничен только `callback_data`: **1–64 байта**. Это другое поле и его длина не зависит от длины отображаемого названия проекта.

## Первичные источники

- [Telegram Bot API — InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton): поле `text` определено как текстовая метка кнопки без указанного максимума; для `callback_data` в той же таблице задан лимит 1–64 байта.
- [Официальный исходный код Telegram TDLib — ReplyMarkup.cpp, строки 563–570](https://github.com/tdlib/td/blob/master/td/telegram/ReplyMarkup.cpp#L563-L570): при обработке `inlineKeyboardButton.text` проверяются корректный UTF-8 и непустое значение; проверка максимальной длины отсутствует.

## Примечание для реализации

В .NET `string.Length` считает UTF-16 code units, а не графемы: emoji за пределами BMP могут занять два значения длины. Для обычных кириллических и латинских имён проектов предел в 50 `string.Length` соответствует 50 символам. Визуальная ширина кнопки при этом определяется Telegram-клиентом, а не Bot API.
