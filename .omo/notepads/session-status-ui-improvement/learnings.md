## 2026-06-09 Task: session-status-ui-improvement
- `SessionManagementHandler.cs` handles all session-related callbacks.
- `KeyboardBuilder.cs` builds the inline keyboards.
- `CallbackPrefixes.cs` defines the callback prefixes.
- `UserSession.cs` tracks the in-memory session state.
- `SESSIONDETAILS:` callback is used to toggle between summary and detailed views.
- `DELETECOMMAND:` and `CONFIRMDELETECOMMAND:` are used to delete/cancel commands.
