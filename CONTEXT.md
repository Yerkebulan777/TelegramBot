# TelegramBot

Бот-диспетчер экспортных и автоматизационных задач BIM: принимает от пользователя набор команд для файлов, ставит в очередь, исполняет через внешние BIM-программы и уведомляет о результате.

## Language

**Задание (Job)**:
Сессия вместе со всеми её командами в очереди выполнения.
_Avoid_: задача, order, batch

**Сессия (Session)**:
Набор команд для набора файлов, созданный одним подтверждением пользователя; единица отслеживания выполнения и уведомления.
_Avoid_: заявка, job batch

**Команда (Command)**:
Одна пара «тип операции + файл» в очереди (одна строка таблицы commands).
_Avoid_: операция, task

**Поток выбора (SelectionFlow)**:
Управляемый состояниями процесс выбора задания пользователем: выбор команд → выбор проекта → выбор разделов → выбор файлов → подтверждение отправки в очередь.
_Avoid_: wizard, intake pipeline, мастер

**Заявка (JobSubmission)**:
Снимок выбранных команд и файлов на момент подтверждения — то, что уходит в очередь.
_Avoid_: payload, request

**Очередь (Queue)**:
Команды в статусе `pending`, ожидающие исполнения Worker'ом.

**Проект (Project)**:
Папка-проект в корне браузера, содержащая каталог `01_PROJECT`.

**Раздел (Section)**:
Папка внутри `01_PROJECT` проекта, имя которой оканчивается известным акронимом (AR, AS, OVK, ...).

**TaskFile / ResultFile**:
XML-файлы обмена между Worker'ом и BIM-исполнителями (Revit, Navisworks); формат определён BIM-контрактом.

**Partition**:
Группа исполняемых путей, внутри которой одновременно выполняется не более одной команды.

**Outbox (NotificationOutbox)**:
Таблица-буфер уведомлений о завершении сессии с at-least-once доставкой.

**Tracked messages**:
Отслеживаемые сообщения чата пользователя, связанные с сессией, — удаляются при очистке истории или сессии.
